Mode d'emploi
Envoyer de l'argent
  1. Choisis le compte à débiter (MTN à gauche, Airtel à droite).
  2. Entre un montant, ou touche un des montants rapides.
  3. Touche "Rapprocher les téléphones".
  4. Entre ton code PIN à 4 chiffres pour autoriser l'opération.
  5. Vérifie que le code affiché correspond à celui du destinataire.
  6. Touche "Confirmer" — la demande est envoyée, mais l'argent ne bouge pas encore.
Recevoir de l'argent
  1. Va sur l'onglet "Je reçois".
  2. Une demande en attente affiche le montant et un code.
  3. Compare ce code avec celui de l'expéditeur.
  4. Touche "Accepter et encaisser" pour valider, ou "Refuser" pour annuler.
Le principe de sécurité

Rien n'est débité tant que : (1) le PIN de l'expéditeur n'est pas validé, et (2) le destinataire n'a pas explicitement accepté. Le code à 4 chiffres partagé garantit que les deux téléphones parlent bien l'un à l'autre.

Créer ton compte

À l'ouverture, tu entres le ou les numéros liés à tes comptes MTN MoMo et/ou Airtel Money. Un code envoyé par SMS vérifie que tu es bien le propriétaire de chaque numéro avant de l'activer. Seuls les opérateurs vérifiés apparaissent ensuite dans l'appli. Pour tester ce prototype, le code de démonstration est 0000. Pour changer de numéro plus tard, va dans Paramètres ⚙ → "Gérer mes numéros".

Ton code PIN

Touche l'icône ⚙ pour définir ton propre code PIN à 4 chiffres (deux saisies pour confirmer). Il est enregistré sur cet appareil et te sera demandé à chaque envoi. Par défaut, le code de démonstration est 1234.

Limites du prototype

Ceci est une maquette : soldes, contacts et transactions sont simulés. Une vraie version nécessiterait une connexion aux API officielles MTN MoMo et Airtel Money, avec validation développeur (KYC).
